# Sakura Listening Room：现状与本轮优化

评估范围：本地仓库与本地浏览器预览，2026-09-12。没有发布到线上，也没有验证生产环境的 CDN、外链或网易云同步任务是否正常。

## 网站现在是什么样

定位已经明确：一个以 J-pop 为线索的个人博客。近黑底色、灰绿点缀、衬线标题、年轮唱片和唱片内页式歌单具有辨识度。最值得继续发展的内容是 Sakura 的选择与感受，以及音乐、阅读、游戏、代码之间的联系。

| 页面 / 模块 | 现状 | 值得加强的地方 |
| --- | --- | --- |
| 首页 | 年轮唱片首屏、6 首选曲、4 篇最近文章、随机图库片段 | 音乐之后的阅读入口与主人身份可以更直接 |
| 音乐 | 日中标题、专辑介绍、聆听短笺、网易云热评；底部播放器跨页保留 | 独立入口、收藏、分享、探索机制 |
| 关于我 | 个人介绍、网易云听歌轨迹、音乐 / 代码 / 收藏三条兴趣线、联系方式 | 从文字直接进入选曲；后续可补充真实的个人选曲缘由 |
| 文章 / 归档 | 6 篇文章，涵盖读书、游戏、技术与生活；有归档、标签、分类 | 旧文需要更多再次被发现的机会 |
| 资源 | 3 个主题、10 项资料，外部网盘链接与提取码 | 后续可补分类筛选、提取码复制、有效性检查 |
| 图库 | 50 张现有图片，首页随机抽取部分展示 | 后续可按现有系列筛选，给图片补充真实来源与说明 |
| 友链 | 朋友与常用网站两组 | 个别头像使用搜索结果页 URL，应替换为稳定图片；朋友介绍可以更具体 |
| 技术 | Hexo 8、自维护 Sakura 主题、Pjax、原生 audio、本地搜索、Giscus、Cloudflare 发布配置 | 主样式已超过 4,000 行，存在多轮覆盖；后续应按模块逐步整理 |

## 本轮完成

1. **独立听歌室 `/listening/`**：复用现有歌曲数据、唱片内页和持续播放器。导航、底部播放器、关于我均可进入，访客在其他页面也能直接找到选曲。
2. **随机选曲**：从实际曲库随机播放，并避开当前歌曲；保留手动选曲与上 / 下一首。
3. **浏览器收藏**：收藏 / 取消收藏当前歌曲，点击收藏标签再次播放。刷新、跨页后仍保留；无法写入存储时显示提示。
4. **歌曲分享**：生成 `/listening/?track=歌曲ID` 链接。访问链接后选中对应歌曲并等待点击播放；剪贴板不可用时提供可选中的链接输入框。
5. **听歌签**：用真实文章与现有曲库生成随机搭配。分别提供播放歌曲、阅读文章的操作，卡片标注 Sakura 并连接关于页。抽签本身不会切断正在播放的歌。
6. **更真实的播放反馈**：顶部显示实际歌手、歌名与播放 / 暂停状态，修复一直显示 Yorushika / ON AIR 的静态标识。
7. **页面过渡**：Pjax 请求期间显示顶部细线，新页面短暂淡入；底部播放器不参与淡入。尊重系统减少动态效果设置，失败与超时会清除加载状态。
8. **交互维护**：非首页也初始化选曲控件；重新进入页面时释放旧 IntersectionObserver；首页滚动入口尊重减少动态效果设置。

新增代码独立放在 `themes/sakura/source/js/listening-experience.js` 和 `themes/sakura/source/css/listening-experience.css`，原有播放恢复逻辑仍由 `midnight.js` 维护。没有增加运行时依赖。

## 验证

- `npm run check`：Hexo 构建成功，36 个 HTML 文件的本地链接检查通过。
- 浏览器实测随机播放、收藏、复制分享链接、歌曲链接直达、听歌签与暂停。
- 播放中通过站内链接进入关于页，再返回听歌室：歌曲继续播放，收藏保留，页面只有一个播放器。
- 分享链接直接打开时，曲目、详情一致，播放按钮处于等待播放状态。
- 听歌室在 390px 与 320px 视口下无横向溢出；检查了手机控件与听歌签的视觉布局。
- 桌面巡查首页、关于、归档、标签、分类、资源、图库、友链及一篇文章：页面可加载，无横向溢出，每页只有一个播放器。测试期间捕获的控制台没有 error。
- 减少动态效果分支已实现并经过代码检查，未切换操作系统偏好做实机验证。外部网盘、好友网站和评论登录不属于本轮功能回归范围。

## 下一轮建议

后续实施记录：图库的系列筛选和大图详情已经在 ohwow 参考轮次落地；资源搜索与提取码复制、文章封面 / 目录视图、正文进度与可调字号的沉浸阅读也已完成。下列建议保留为最初评估记录，其中已完成的项目不再属于待办。

**优先补内容**：给最喜欢的几首歌写 2–3 句真实的“我为什么留住它”。现有专辑介绍与热评提供背景，而具体记忆、当时读的书、对某段旋律的感受，最能体现个人气息。这部分需要 Sakura 的真实素材，不宜代编经历。

**再做页面细化**：图库增加系列筛选；资源页增加搜索与复制提取码；归档加入按兴趣进入旧文的入口。文章可以增加可选的 `listening_track` 字段，由作者主动选择配乐，避免随机搭配被误认为作者推荐。

**最后收拢技术债**：把主 CSS 按导航 / 首页 / 音乐 / 文章 / 移动端拆分，逐步减少叠加覆盖；将 `after_render:html` 中的 HTML 字符串替换迁到明确的 Pug 组件入口。保留当前设计，在后续修改相应模块时逐步进行。
