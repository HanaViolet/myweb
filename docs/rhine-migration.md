# RhineLabUI 博客迁移 · 2026-10-15

本次直接采用 [LBEILC/RhineLabUI](https://github.com/LBEILC/RhineLabUI) 的原生网页实现，版本固定为 `12cc5e4013acb9408f753ff71de6b8492299b7c8`，替换 Hexo 构建与 Sakura 主题入口。迁移源码通过 Git 发布，线上状态以 Cloudflare Pages 的部署结果为准。

## 保留与适配

76 个上游源码 / 模型文件逐字节保留，SHA-256 记录在 `rhine-upstream.json`，由内容检查校验。其中包括场景、相机、模型查看器、开场、解密、字体、配色、响应式布局、声音和核心动效。原模型没有重新制作或减面，默认画质没有降低。

修改的上游源码限于：

- `src/data.ts`：读取从博客生成的数据，扩展正文和路径等字段。
- `src/main.ts`：接入正文、目录、评论、路由和音乐；让档案刻度支持五列不同数量；调整少量栏目文案。
- `src/startup.ts`：加入直接阅读链接，并纳入键盘焦点循环。

博客行为集中在 `src/blog.ts`、`src/blog.css` 和 `src/entry.ts`。正文继续使用原右侧阅读区域。桌面长文区域额外预留页脚空间，移动端沿用上方模型、下方独立滚动正文。原版品牌和三维界面保持完整；作者信息、网页标题、PWA 名称和内容归属为 Sakura。

上游未公开分发的 Novecento Webfont 没有下载或打包，沿用其原生固定图形回退。MIT、MiSans、Rolling Number 及 PR #15 贡献署名随资源保留。

## 内容入口与交互

- 左右切列，上下选择，Enter 读取；原版搜索、收藏和模型查看器继续使用。
- 搜索包含正文与标签，不只标题。
- 正文 / 目录 / 留言三页签；目录支持跳到章节，专注阅读使用 `?reader=1`。
- 原有网易云 `?track=music` 分享入口仍有效。选曲播放后跨站内导航保持连续，并暂时压低到关闭终端环境音乐；暂停后恢复用户的终端音乐偏好。
- 播放器保留上一次曲目、位置和音量，刷新后等待用户点击播放。
- Giscus 沿用原仓库、分类与文章路径，按用户点击加载；没有自动发布评论。
- 原每日网易云数据更新与每周热评工作流继续使用原数据路径；关于页保留部署验证所需时间标记。
- PWA 原子缓存当前版本的界面、模型、字体和正文。私人 MP3、图库原图和远程音乐按需联网使用，避免首次访问下载整个媒体库。

## 验证方式

`npm run check` 执行 TypeScript 检查、生产构建、源内容 / 媒体数量与旧地址核对、76 个原版文件哈希检查，以及全部生成 HTML 的本地链接检查。

预览服务运行时，`npm run check:browser` 用 Chrome 检查五列不同数量的循环切换、全文搜索、文章末段与配图、收藏刷新恢复、浏览历史、旧地址直达、音乐连续播放、图库系列、资源提取码、390×844 竖屏滚动和禁用 JavaScript 阅读。

`node tools/check-blog-visual.mjs` 检查原版默认画质、首次启动、详情解密、360° 查看器、暗色主题、页脚与正文边界及离线打开嵌套文章地址。截图和机器可读报告输出到不提交的 `artifacts/rhine/`。手机验证使用 Chromium 视口模拟；没有宣称实机 iPhone / Safari 已验收。Giscus 登录留言和外部网盘 / 远程音频服务的实时可用性未做端到端验收。

## 构建与回退

Cloudflare Pages 的新构建命令为 `npm run build`，输出目录继续为 `public`，Node >=20.19。后台若仍是 `npx hexo g`，发布前需要更新。本次迁移没有修改 Cloudflare 后台构建配置。

原 `source/`、`themes/`、Hexo 配置及此前未提交的主题改动均保留。开始本次迁移时的 `package.json`、锁文件和 README 另存于本机忽略目录 `.migration-backup/`；此前说明另存 `docs/legacy-listening-room.md`。恢复旧构建时，可从该备份恢复 package 文件并重新安装依赖；新前端和源博客内容互相独立，不需要删除内容。备份不进入 Git，迁移确认前应保留。
