## 📖 简介 (Introduction)

这是我的个人博客源码仓库，基于 **Hexo** 框架构建，使用了 **Butterfly** 主题，并由 **Cloudflare Pages** 自动构建发布。在这里我记录技术笔记、生活感悟和学习历程，也保存一份属于自己的夜间选曲。
