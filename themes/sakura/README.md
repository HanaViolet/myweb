# Sakura Listening Room

This is the site's self-contained Hexo theme. It includes the Pug layouts,
Stylus styles, helper/tag scripts, search/comment integrations, and the Sakura
listening-room player used by this repository.

The rendering layer was initially copied from Butterfly 5.5.3 and adapted for
this design. Butterfly is Apache-2.0 licensed; keep [`LICENSE`](LICENSE) and
[`NOTICE.md`](NOTICE.md) with redistributed copies. Sakura-specific changes and
the listening-room UI are maintained in this project.

The site-level settings live in the repository root at `_config.sakura.yml`.
